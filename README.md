Yaya's Sideral Bocatas es una pequeña demo hecha con Godot 4.5.

Es un juego de cocina similar a Cooking Mama donde usas el ratón para dar los pedidos a tus clientes.

Su desarrollo ocurrió entre noviembre de 2025 y enero de 2026 por un grupo de 3 estudiates universitarios.

Todo el código es libremente (CC0) explorable y reusable.
